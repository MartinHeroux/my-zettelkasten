# Roadmap and ideas

This is a **living list of possibilities, not a release commitment**. The guiding rule is to add features only when a real workflow problem justifies their cost. Please record the problem and a small acceptance test before implementation.

| Idea | Status | Why consider it? |
|---|---|---|
| Paste screenshots/images from clipboard | Idea | Reduce interruptions while reading or sketching |
| Link an existing PDF/file without copying it | Idea | Avoid duplicating PDFs already managed in Zotero/Dropbox |
| Direct Zotero item links from citation keys | Investigate | Jump to source without manual lookup; needs reliable identifiers |
| Muted styling for long Markdown link targets | Idea | Improve readability while preserving editable syntax |
| Optional rendered Markdown/figure preview | Idea | Inspect tables and figures without leaving the editor |
| Multiple tabs or split-note view | Evaluate after use | Compare two ideas side by side |
| Search Zotero annotations from app | Deferred | Only if separate searches become a repeated problem |
| Automatic Zotero note import or reciprocal pointers | Deferred | Avoid two independently editable versions and sync conflicts |
| Additional OS support | Needs testing | Linux Mint is the currently tested environment |
| More advanced templates, tags, or graph view | Deferred | Avoid complexity without a demonstrated payoff |

## How to propose an improvement

Describe: **current friction**, **expected behaviour**, **minimal change**, **how to test it**, and **possible downsides**. Use GitHub Issues when available. Bugs that risk data loss take priority over optional features.
