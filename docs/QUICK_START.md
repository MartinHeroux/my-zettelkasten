# Quick start: capture, develop and connect

1. **Create or open a collection.** Use the welcome screen or File menu. File → Recent Collections reopens a previous collection. The app remembers your current collection; Close Collection returns to the welcome screen.
2. **Capture a fleeting thought.** Press `Ctrl+Shift+N` or choose **New Note ▾ → Fleeting Note**. Write freely; autosave stores it in `inbox/`, separate from the main notes list.
3. **Process Inbox.** Click **Inbox**, select a note and open it. **Develop** creates a Permanent note containing the original thought, while preserving the fleeting original. Rewrite the developed copy into a useful explanation and connect it to related notes. Alternatively, transfer the useful parts into an existing note or project.
4. **Discard the processed original.** Reopen it from Inbox and click **Discard**. Confirm permanent deletion of the original and its recovery copies. This bypasses Trash; the developed Permanent note is kept. Cancel leaves the original unchanged.
5. **Create and connect main notes.** Use New Note for Permanent (`Ctrl+Shift+I`), Literature (`Ctrl+Shift+P`), Project (`Ctrl+Shift+J`) or Entry-Point (`Ctrl+Shift+O`). Type `[[`, search, and select with arrows and Enter. **Linked Note** (`Ctrl+Shift+L`) creates a linked Permanent note; `Alt+Left` returns. Develop fleeting notes before creating linked main notes.
6. **Read a paper.** Keep PDFs and annotations in Zotero. Select the Better BibTeX export through **Navigate → Choose Bibliography**. Open **References** (`Ctrl+Shift+R`) to create/reopen a Literature note. Type `[@` and search by author, title, year or key. Suggestions show keys only; Enter inserts `[@key]`.
7. **Develop an output.** Use a Project note for an outline, decisions and next actions. Link to reusable Permanent and source-specific Literature notes. Archive finished Project notes without deleting their linked knowledge.
8. **Find things again.** Use sidebar search and filters, pin entry points, follow Links to / Linked from, or use Back/Forward for visit history. `Ctrl+Enter` follows a Markdown link at the cursor.

## Boundaries

- Literature notes live in the app; Zotero manages references, PDFs and annotations. Bibliography access is read-only.
- Attach (`Ctrl+Shift+A`, also in the Note menu) copies a file into `attachments/`.
- **Note → Move to Trash** remains recoverable. **Discard** on a fleeting note is permanent and has a separate confirmation.
- Back up the whole collection, including Inbox. Backups and sync history are independent of Discard.
- Existing category metadata uses `idea`, `paper`, `overview` and `project`; user-facing names have changed without requiring migration.
