# Quick start: a reading-to-writing workflow

1. **Create a collection.** Start the app with `--collection ~/Zettelkasten-Test`. Follow the pinned **Start here** note and its linked tutorial.
2. **Capture an idea.** Press `Ctrl+Shift+I` and type its title after `# `. Keep the explanation understandable to your future self.
3. **Connect ideas.** Type `[[` and search by note title; choose with arrows and Enter. Use `Ctrl+Shift+L` to create a linked idea and jump into it. `Alt+Left` returns to the originating note.
4. **Read a paper.** Keep PDFs and annotations in Zotero. Select your bibliography using File → Choose bibliography, then use **References** to open/create an associated Paper note. Type `[@` to cite other references. Record your observations in the Paper note and develop reusable claims as Idea notes.
5. **Develop an output.** Create a Project note for a manuscript or teaching session; link existing Idea notes into an outline. Archive the project when finished while retaining reusable notes.
6. **Find things again.** Use sidebar search, Pinned, Recent, Links to, and Linked from. Back/Forward track visited notes; they do not automatically choose graph links.

## Important boundaries

- Paper notes live as Markdown in the app; Zotero remains the authority for PDFs, bibliography and annotations.
- Attach copies a figure/file to `attachments/`. For full PDFs already in Zotero, a citation may be preferable.
- Your bibliography export is read-only. If moved, reselect it from File → Choose bibliography.
- Use a disposable collection while learning and maintain independent backups.

See [Zotero setup](ZOTERO_SETUP.md) and [Backup and recovery](BACKUP_AND_RECOVERY.md).
