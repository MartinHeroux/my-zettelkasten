# Reading, thinking and writing

1. Capture a fleeting thought with **Ctrl+Shift+N**. Open **Inbox** to revisit it.
2. **Develop** creates a separate Permanent note and leaves the original intact.
3. Read PDFs and write source-specific literature notes in **Zotero**.
4. Choose your Better BibTeX export under **Navigate → Choose Bibliography**. Type `[@` to insert a citation key. Double-click a Sources cited entry to inspect its reference.
5. Write your explanations, arguments and connections in Permanent notes. Type `[[` to link ideas; use Linked Note to branch.
6. Use Project notes to assemble questions, outlines and decisions. Save after Archive / Unarchive; find completed projects under Archived.
7. Processed or mistaken notes can go to **Note → Move to Trash** and be restored later. **Note → Delete Permanently** removes the open note and recovery versions after confirmation.

Literature creation and the References browser have been removed. Existing literature files remain readable under All / Uncategorised; transfer their contents to Zotero manually if desired. No automatic migration occurs.

Recovery stores up to ten previous saved versions per note, including autosaves. It is separate from Trash. See [backup and recovery](BACKUP_AND_RECOVERY.md).
