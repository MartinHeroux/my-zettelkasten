# Start here — Personal Zettelkasten v0.5

## Your first ten minutes

1. Start with a **disposable collection**. The app creates two editable onboarding notes only when the collection is empty on first launch.
2. Create an **Idea** note (`Ctrl+Shift+I`); type the title after `# `.
3. Use `[[` to search for and link another note. Use **Linked note** (`Ctrl+Shift+L`) to create a new idea and jump to it; `Alt+Left` returns.
4. Create a **Paper** note from **References** after choosing your Better BibTeX export under File → Choose bibliography. The export is read-only. `[@` opens citation completion.
5. Add a figure using **Attach** (it copies the file into `attachments/`). For full PDFs already in Zotero, prefer a citation rather than duplicating the PDF.
6. Find notes via the left search field, Pinned and Recent, or follow Links to / Linked from in the right pane.

## Note roles

- **Paper**: what a source says, its methods, and your source-specific observations.
- **Idea**: a developed, reusable argument or question, linked to evidence and related ideas.
- **Overview**: an entry point into several ideas, not a mandatory taxonomy.
- **Project**: writing/teaching project outline and decisions; archive after completion.

## Safe adoption

The app is a **pilot candidate**. Before moving irreplaceable work, test external-change conflicts, backups, restores, and your live bibliography export. Back up the full collection to a separate location; recovery copies are not a substitute for independent backups. Keep Zotero's database in its supported location, not a live cloud-synced folder. The app does not edit Zotero's database or synchronize Zotero notes.

## Navigation

Back and Forward follow *your visit history*, not graph links. Ctrl+Enter while the cursor is inside a Markdown link follows the link. Supported explicit external links include HTTPS and Zotero URLs. Missing local targets produce a warning.

## Moving the collection

Move the whole folder (notes, attachments, settings, references if local). Relative links between notes and attachments remain valid. An external bibliography path may need updating. You can select a different collection at launch with `--collection /path/to/collection`.
