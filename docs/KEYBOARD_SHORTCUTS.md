# Keyboard shortcuts

| Action | Shortcut |
|---|---|
| New Fleeting | `Ctrl+Shift+N` |
| New Permanent | `Ctrl+Shift+I` |
| New Literature | `Ctrl+Shift+P` |
| New Entry-Point | `Ctrl+Shift+O` |
| New Project | `Ctrl+Shift+J` |
| New linked Permanent note | `Ctrl+Shift+L` |
| Attach file | `Ctrl+Shift+A` |
| Save | `Ctrl+S` |
| Open note | `Ctrl+O` |
| Search notes | `Ctrl+Shift+F` |
| Find in current note | `Ctrl+F` |
| Back / Forward | `Alt+Left` / `Alt+Right` |
| Pin / Unpin | `Ctrl+Shift+K` |
| References | `Ctrl+Shift+R` |
| Undo / Redo | `Ctrl+Z` / `Ctrl+Y` |
| Follow Markdown link at cursor | `Ctrl+Enter` |
| Note-link completion | Type `[[`, then arrows / Enter / Esc |
| Citation completion | Type `[@`, then arrows / Enter / Esc |

Desktop environments can reserve some combinations. The app's **Help → Keyboard shortcuts** menu displays the in-app reference.
